# Physics-Guided Vehicle Time-Series Forecasting

This repository contains a small learning experiment on vehicle speed prediction.

The purpose is to compare a data-driven prediction model with a simple physics-guided model. The experiment will investigate whether including a physical relationship can improve short-term speed predictions when vehicle sensor measurements contain noise.

The project is inspired by my academic background in physics, statistics and computer science, together with my interest in machine learning for safety-critical automotive systems.

## Research Question

Can a simple physical-consistency constraint improve short-term vehicle speed prediction under noisy sensor conditions?

## Current Status

The project is under development. The first stage will generate a small synthetic vehicle time-series dataset containing speed, acceleration, throttle and braking signals.
